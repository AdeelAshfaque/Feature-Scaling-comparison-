# Feature Scaling Comparison

This repository contains my Machine Learning Lab 6 work on comparing different feature scaling techniques.

## Contents

* `lab-6.ipynb` — Jupyter Notebook containing the implementation, experiments, and comparison of feature scaling methods.
* `clean_churn.csv` — Dataset used for the experiments.
* `Week6_ML_FA26.pdf` — Lab instructions/reference material.

## Topic

The lab focuses on **feature scaling** and its effect on machine learning models. Different scaling techniques are applied and compared to understand their impact on model performance.

## Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Matplotlib / Seaborn

## How to Run

1. Clone this repository.
2. Open `lab-6.ipynb` in Jupyter Notebook or JupyterLab.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells in order.
